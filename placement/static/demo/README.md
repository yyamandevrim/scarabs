# Overview media

These assets derive from this repository's working product captures. See `../vendor/README.md` for source captures, crop/re-encode methods and runtime playback rules. The map terrain image is interim and must be re-captured after the separate map rebuild.

Smoke footage: [Wildfire Near Monserrate](https://commons.wikimedia.org/wiki/File:Wildfire_Near_Monserrate.ogv), Peter Angritt (Mrtony77), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Changes: app detection overlays, crop/resize, WebP and H.264 re-encoding. These footage derivatives remain available under CC BY-SA 4.0. Underlying map data: NLS Finland, Syke and Luke, CC BY 4.0, with dataset details supplied by `/api/config`.
