# Overview media

These assets derive from this repository's working product captures. See `../vendor/README.md` for source captures, crop/re-encode methods and runtime playback rules. The map preview is a real capture of the merged 360° launch map default view. Desktop is captured at 1440×900 and exported to 1280×800; phone is captured/exported at 393×852. Both are WebP quality 78, method 6, with source dimensions and lazy loading in the Overview picture. The selected source is 119,632 B desktop or 41,208 B phone.

Smoke footage: [Wildfire Near Monserrate](https://commons.wikimedia.org/wiki/File:Wildfire_Near_Monserrate.ogv), Peter Angritt (Mrtony77), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Changes: app detection overlays, crop/resize, WebP and H.264 re-encoding. These footage derivatives remain available under CC BY-SA 4.0. Underlying map data: NLS Finland, Syke and Luke, CC BY 4.0, with dataset details supplied by `/api/config`.
