# Overview media

These assets derive from this repository's working product captures. See `../vendor/README.md` for source captures, crop/re-encode methods and runtime playback rules. The map preview is a real capture of the merged 360° launch map default view. Desktop is captured at 1440×900 and exported to 1280×800; phone is captured/exported at 393×852. Both are WebP quality 78, method 6, with source dimensions and lazy loading in the Overview picture. The current previews show Sipoonkorpi and Nuuksio; their exports are maintained by the map implementation.

Smoke footage: [Wildfire Near Monserrate](https://commons.wikimedia.org/wiki/File:Wildfire_Near_Monserrate.ogv), Peter Angritt (Mrtony77), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Changes: app detection overlays, crop/resize, WebP and H.264 re-encoding. These footage derivatives remain available under CC BY-SA 4.0. Underlying map data: NLS Finland, Syke and Luke, CC BY 4.0, with dataset details supplied by `/api/config`.


Round 2 uses only `event-frame.webp` and `event-clip.mp4` from the same captured event, af27f33e9e244d9db8f18eb4276fd1ad. The clip is a native 640px-wide crop from y=80 to y=360, H.264 / 15fps. The still is taken one second into that same clip so smoke reads clearly. The crop omits old in-frame annotation text without repainting pixels. Reproduce with `scripts/prepare_overview_media.py SOURCE_EVENT.webm OUTPUT_DIRECTORY`. Its original event opening time and score (13:47:51 UTC; 59% after packet quantization) drive the DOM report, evidence context and station panel. Camera selection is a local interactive input and updates the entire demonstration case together; per-camera identifiers distinguish those cases. It does not fetch a different live camera or alter the archived source record. The phone uses real DOM buttons, not a video of app controls. Retired screen captures and nested-player movies were removed.
