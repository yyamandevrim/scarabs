# Shared behaviour vectors for firmware/acorn_mcu/acorn_logic.h.
# Run by firmware/test/test_logic.cpp (the real firmware code, compiled on the host)
# and by station/tests/test_mcu.py (the Python simulated MCU), so both stay identical.
#
# Default settings: 12-bit ADC, analog inverted (more IR = lower voltage),
# trigger 150 ms, release 1000 ms, LED flame hold 3000 ms, Linux timeout 5000 ms.
#
# "scenario NAME" starts fresh logic.
# Step: t_ms raw digital linux_state -> triggered led level
#   linux_state: "-" = no message at this time, otherwise the state Linux sends.
#   led: 1 normal, 2 smoke pending, 3 degraded, 4 flame, 5 linux silent.
#   level: expected relative IR level 0..1000, "-" = not checked.
