# ACORN map b-roll

Captured 2026-11-15 from commit `0027611`, **working tree with uncommitted changes**. Source: this repository’s real placement app at `http://127.0.0.1:8302/map`, plus the local `placement/comparison-chart.html` file. No tracked source edited by the capture agents.

43 primary clips (282.0 seconds), 31 1080 derivatives, 57 PNG stills.

## Capture conditions

- Headless/offscreen Playwright Chromium 1255. No real display recording, browser chrome, OS windows, visible cursor, external runtime map service, external upload or fabricated application pixels. English UI. Prepared local NLS/Syke/Luke rasters were available; no large download was needed.
- Landscape: 1440×810 CSS, DPR 2; 2880×1620 native PNG/MP4. Every landscape clip also has a 1920×1080 derivative. Phone: 393×852 CSS, DPR 3; 1179×2556 PNG and 1180×2556 MP4 with one padding column. Detail crops retain native device scale. Full-page phone stills are taller.
- All final MP4s: H.264, yuv420p, 30 fps CFR, no audio, CRF 14 (chart CRF 14), faststart. Each clip has at least one second of start/end hold. Static page/state clips are deliberately static.
- Motion uses separately rendered real browser screenshots per input step, assembled at 30 fps. It is frame-stepped capture, not a wall-clock latency measurement. No optical flow, frame interpolation, fake loading, or low-rate recording padded across a movement. Static holds repeat a frame. The decoded pan has actual terrain movement on 118 of 119 adjacent transitions in its four-second input segment; the one unchanged transition is the final endpoint hold. See `qa/encoded-motion-check.json`. Motion clips are encoded from an exact 30 fps image pipe to retain each rendered input sample. Zoom is a native step because this working tree disables Leaflet zoom animation.
- Recalculation takes cut from an actual before state to the actual completed state. Actual computation waits are omitted, never sped up as a claimed latency. `raw/metadata.json` records each omitted wall-clock wait. Initial/default and height-table clips start after completion.
- Default input: 600 m AGL; Quick 120 m; three active 120° sectors, heading fixed at 0°; tilt 10°, VFOV 50°, model range 12 km, smoke 50 m above canopy; no polygon. Two available sites: Sipoonkorpi A and Nuuksio B. Individual geometry clips accumulate the selected A edits (tilt 20°, VFOV 70°, range 10 km, smoke 80 m). State JSON records exact fields.
- These are simulated geometric visibility results, not measured optical detection, flight permission or on-device deployment evidence. Standalone chart is a static generated 40 m-grid report and is captured honestly as a hold.

## Coverage and unavailable controls

Covered: fully loaded default 360° map; real pan and zoom; both sites; Compare/Breakdown/Data; every height; Quick/Detailed grids; all four scenarios; live height comparison; area accounting and secondary metrics; geometry and position edits; map-click relocation; forest/water layers and expanded layer chooser; priority start/draw/finish/result/clear/cancel; genuine coordinate validation and the explicit Recalculate button; responsive phone panels and full pages; standalone chart and native detail crops.

Current product has **no heading control, camera-pair selection, three-camera reference switch, export or report action**. README says these historical controls were removed by the full-circle model. The legend changes automatically by scenario/visibility and has no manual legend-toggle control. Forest/water layer toggles are captured. Native scenario/height/detail dropdown popup options are omitted because offscreen screenshots do not include their browser popup surfaces; the actual selected values and resulting states are captured. Native segment-title tooltips in the standalone chart are omitted because headless screenshots do not expose their pixels. No tooltip is fabricated.

## Verification and product observations

Every deliverable MP4 was ffprobed with asserted dimensions/fps/codec/pixel format, fully decoded once, and visually reviewed at start/middle/end. PNG states and detail crops were reviewed. See `qa/verification.json` and review sheets. Superseded recording experiments are under `qa/rejected-css-resolution/` and are excluded from all deliverable counts/contact-sheet entries. Source commit/status/hashes are in `raw/source-*`.

No application source fixes were made. Product presentation issue: canopy-ground rounds both site totals to ≈0 ha while still displaying a 1.3× verdict and positive camera-share bars. The ratio and shares use raw values, while labels round separately; this is a confusing presentation rather than evidence of an engine error. Native selector popups and chart title tooltips are not available in the offscreen screenshot surface and were omitted. Scroll clips stop moving naturally at the panel boundary, then hold. Captures include the genuine coordinate-validation state, marked deliberately as an error-state take.
